Speech models and embeddings run on the application host. Gemini generates answers using transcripts and retrieved context. The streaming voice route uses sentence-level PII checks; the non-streaming route also applies a groundedness judge.

MEASURED EXPERIMENT

Domain-focused speech recognition

1.02% WER

Fine-tuned Whisper on 32 synthetic validation clips, compared with 5.78% for the base model. On the separate real-speech test, hotword-biased base Whisper performed slightly better than the fine-tune.
